Session logins

Wise Old Man only ever tells us a session has ended - the hiscores do not move until logout. The Dink plugin tells us when one started, so a long session stops landing in the ten minutes we happened to notice it in. Nothing on the dashboard reads this yet; it is being collected first.

Each player installs Dink from the RuneLite Plugin Hub, then pastes their own URL below into the setting called Custom Metadata Handler. That field is the only one they need - the Discord webhook box above it can stay empty. Ask them to untick Send Discord Profile and Send Clan Name while they are there; we throw both away, but there is no reason to send them.

A URL is a password. Send it to that player and nobody else, and issue a new one to retire a leaked one.
